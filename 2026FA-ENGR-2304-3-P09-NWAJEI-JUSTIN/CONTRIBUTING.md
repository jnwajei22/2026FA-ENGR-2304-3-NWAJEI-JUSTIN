# Contributing to ENGR 2304 P09

This is a course collaboration exercise. Two **real ENGR 2304 classmates** are invited to propose distinct improvements through pull requests.

## How to propose a change

1. Fork this public repository on GitHub.
2. Create a branch in your fork (for example, `improve-pressure-status`).
3. Modify `P09/2026FA-ENGR-2304-3-P09-NWAJEI-JUSTIN.ino` or `P09/README.md`.
4. Briefly explain the change and how you tested it.
5. Open a pull request to `jnwajei22/2026FA-ENGR-2304-3-NWAJEI-JUSTIN`, branch `main`.

Ideas: clarify pressure-input error messages, improve Serial status output, strengthen reset handling, or improve the Tinkercad setup notes.

No fabricated PRs, contributor accounts, or simulated review records should be used. Only genuine classmate contributions count.

**Safety:** This is an indicator-only simulation; do not add actual compressor actuation, pyrotechnic ignition, or launch-control wiring.
